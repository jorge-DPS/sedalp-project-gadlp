# UI compartida

Coloca aquí únicamente componentes visuales reutilizables por varias vistas, por ejemplo `BaseButton`, `BaseModal`, `BaseTable`, `BasePagination` o `AccessPageHeader`.

Las páginas que son destino de Vue Router deben vivir en `src/views/<area>/`. Los componentes exclusivos de una funcionalidad pueden agruparse en `src/components/<area>/`, fuera de esta carpeta compartida.
